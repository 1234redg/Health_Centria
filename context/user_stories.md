# User Stories

Format: **As a [user], I want to [action], so that [benefit].**

## Patient

- **Register/Login/Logout/Reset Password** — so I can securely access my account.
- **View & update my profile** — so my information stays accurate.
- **View schedule of services** — so I know which service is offered on which day.
- **Request an appointment** (pick service + date) — so I don't visit on the wrong day.
- **View appointment status & history** — so I know if it's pending, confirmed, or declined.
- **Receive notifications** — so I'm alerted when my appointment is confirmed.
- **View announcements** — so I stay informed of schedule changes or health programs.

## Health Center Staff

- **Login/Logout** — so only authorized staff access resident data.
- **Register a walk-in resident** — so they can be seen without a prior appointment.
- **View & update a resident's profile** — so records stay current.
- **View a resident's visit history** — so I have context before a consultation.
- **Record a visit** (vitals, diagnosis, treatment plan) — so history is captured digitally, like the old ITR form.
- **View & respond to appointment requests** (confirm/decline) — so patients know whether to come in.
- **Update health services & schedule** — so patients always see accurate info instead of a printed sign.
- **Post announcements** — so patients are informed without a printed notice.
- **View dashboard** — so I can manage today's appointments and patients at a glance.
- **View appointment/patient statistics & generate reports** — so I can report on health center activity.

## Administrator

- **Login/Logout** — so sensitive functions stay protected.
- **Create & deactivate staff accounts** — so only current staff have access.
- **Assign roles & configure permissions** — so access matches each person's responsibilities.
- **View system statistics** — so I can monitor overall performance.
- **Generate patients-served / appointments-services reports** — so I can report to barangay officials.
- **Configure automatic backups** — so resident records aren't lost like a paper ITR could be.
- **View access/audit logs** — so I can monitor who viewed or edited resident records.
